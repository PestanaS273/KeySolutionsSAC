# Documentación — sitio de Key Solutions S.A.C.

Sitio corporativo en `https://keysolutionssac.com`. Empresa, insumos para el sector financiero,
desarrollo de software y la puerta de entrada a KeyERP (`https://keyerp.keysolutionssac.com`,
que es otro repositorio: `KeyERPWeb`).

| Documento | Qué contiene |
|---|---|
| [`bitacora.md`](bitacora.md) | Qué cambió y cuándo. **Se actualiza en cada entrega.** |
| [`contenido.md`](contenido.md) | Dónde vive cada texto, dato y logo, y cómo se edita sin tocar componentes. |
| [`despliegue.md`](despliegue.md) | Build, subida a cPanel, formulario (Web3Forms), Search Console, el video del hero y verificación. |
| [`decisiones.md`](decisiones.md) | Reglas de contenido y diseño que no se negocian, con su porqué. |

**Última actualización del sitio: 2026-09-14** (ver bitácora).

## Cómo se mantiene esta carpeta

- Cada entrega agrega una entrada en `bitacora.md` con fecha, commit y qué cambió para el visitante.
- Si un cambio mueve contenido de sitio (un dato pasa de una página a un fichero de datos, por
  ejemplo), se corrige `contenido.md` en el mismo commit.
- Una regla nueva de contenido o diseño va a `decisiones.md` con su motivo; sin motivo no es regla.
